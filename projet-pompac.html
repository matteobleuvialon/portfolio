POMPAC · Projet en entreprise · 2026

L’énergie, rendue lisible.

Une interface TV qui rassemble production photovoltaïque, autoconsommation et météo.

Contexte

POMPAC · Projet en entreprise · 2026

Outils mobilisés
  • HTML / CSS / JS
  • PHP
  • API REST
  • Raspberry Pi

Le besoin.

Rendre les données de production photovoltaïque consultables depuis une interface TV, en réunissant plusieurs sources dans un même écran.

Ma contribution.

J’ai développé cette interface en autonomie dans le cadre de mon poste d’assistant marketing chez POMPAC, puis participé à son déploiement avec le service IT.

  1. Développer l’interface en HTML, CSS et JavaScript, avec PHP.
  2. Intégrer les API SolarEdge et Météo-France pour réunir les informations utiles.
  3. Afficher la production instantanée, l’autoconsommation, la météo et un historique sur huit jours.
  4. Tester puis déployer l’interface sur un Raspberry Pi.

Ce que j’en retiens.

Ce projet relie le développement d’une interface à un usage réel en entreprise : connecter des sources de données, choisir ce qui doit être visible et prendre en compte le support final d’affichage.

La suite.

Approfondir la gestion des réponses indisponibles et la documentation des échanges entre les API et l’interface.

Liens & ressources
