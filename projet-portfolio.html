Mon parcours, en ligne.

Un site multipage pour relier mes réalisations, mes compétences et ma progression.

Contexte

Epitech · Projet scolaire · 2026

Outils mobilisés
  • HTML sémantique
  • CSS responsive
  • JavaScript

Le besoin.

Construire un portfolio évolutif répondant au sujet Epitech : plusieurs pages, des réalisations contextualisées, une réflexion sur les apprentissages et des accès clairs au CV et au contact.

Ma contribution.

Le contenu s’appuie sur mon CV et mes réalisations. Cette première version a été construite avec l’assistance de Codex ; je dois comprendre, vérifier et adapter le code pour me l’approprier.

  1. Séparer l’accueil, les projets, le parcours, la progression et le contact.
  2. Décrire chaque projet avec son objectif, ses technologies et une réflexion sur les apprentissages.
  3. Utiliser HTML pour le contenu, CSS pour la présentation et JavaScript pour les interactions.
  4. Préparer une structure statique compatible avec une publication automatisée sur GitHub Pages.

Ce que j’en retiens.

Ce portfolio est un support d’apprentissage en cours : comprendre les liens entre les pages, le responsive, les événements JavaScript et les usages du clavier. L’existence de cette version ne suffit pas à démontrer ma maîtrise de tout son code.

La suite.

Reformuler le fonctionnement de chaque interaction, ajouter mes propres captures et publier le site après vérification.

Liens & ressources

Le site que vous consultez est la démonstration. Les sources sont organisées en fichiers HTML, une feuille CSS et un script JavaScript ; le lien du dépôt sera ajouté après sa création.
