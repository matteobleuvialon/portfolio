Epitech · Projet scolaire · 2026

Mon parcours, en ligne.

Un site multipage pour relier mes réalisations, mes compétences et ma progression.

Contexte

Epitech · Projet scolaire · 2026

Outils mobilisés
  • HTML sémantique
  • CSS responsive
  • JavaScript

Le besoin.

Construire un portfolio évolutif répondant au sujet Epitech : plusieurs pages, des réalisations contextualisées, une réflexion sur les apprentissages et des accès clairs au CV et au contact.

Ma contribution.

Pour ce projet, j'ai rassemblé mes réalisations, mes expériences et mes compétences dans un portfolio structuré autour de plusieurs pages. J'ai travaillé sur l'organisation des contenus et préparé la mise en ligne du site en utilisant Git, GitHub et GitHub Pages. Ce projet constitue également un support pour approfondir mes connaissances en HTML, CSS et JavaScript.

  1. Séparer l’accueil, les projets, le parcours, la progression et le contact.
  2. Décrire chaque projet avec son objectif, ses technologies et une réflexion sur les apprentissages.
  3. Utiliser HTML pour le contenu, CSS pour la présentation et JavaScript pour les interactions.
  4. Versionner le projet avec Git, publier les fichiers sur GitHub et configurer GitHub Pages pour rendre le portfolio accessible en ligne.

Ce que j’en retiens.

Ce projet m'a permis de mettre en pratique les principales étapes de publication d'un site web. J'ai notamment découvert comment initialiser un dépôt Git, enregistrer les modifications avec des commits et envoyer mon travail sur GitHub. Je souhaite maintenant approfondir le fonctionnement des interactions JavaScript et continuer à améliorer la structure du site.

La suite.

Continuer à faire évoluer le portfolio au fil de ma formation, en ajoutant de nouveaux projets, des captures de mes réalisations et des retours d'expérience plus détaillés. Je souhaite également améliorer progressivement l'accessibilité, les performances et l'expérience sur mobile.

Liens & ressources

Le portfolio est hébergé sur GitHub Pages. Son code source et l'historique des modifications sont accessibles sur GitHub .
